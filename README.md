# AeroSim2026 Flight Simulator Tracker  

### Features  
- Create a random flight
- Make your own Flight
- Generate multiple flight paths
- Save the flight and flight plan  

### Discription  
This is a desktop flight planning and tracking application meant for flight Simulator users. This is written in C# 14 and .NET 10. AvaloniaUI 11.3.13 Framework is used for the main UX. ReactiveUI is the MVVM frameworks and FluentUI is used for the styling framework.
